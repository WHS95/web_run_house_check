# `lib/motion/` — 인터랙션 · 모션 레이어

제스처 UI가 **네이티브처럼 느껴지게** 만드는 순수 계산을 격리하는 레이어.

`lib/domain/`이 비즈니스 룰을 격리하듯, `lib/motion/`은 **인터랙션 물리**를 격리한다.
둘은 성격이 다르므로 섞지 않는다 — 출석 정책은 `lib/domain/attendance/`, 시트가 닫힐지 말지는 `lib/motion/`.

---

## 왜 이 레이어가 필요한가

> "만들다 보면 시트마다 조금씩 다르게 동작한다."

이게 실제로 일어났다. 이 레이어를 만들기 전 상태:

- 시트/모달 **19개** 중 드래그로 닫히는 건 **1개** (`MapBottomSheet`)
- 그 1개조차 **속도를 무시**하고 `offset.y > 100`으로만 판정 — 빠르게 튕겨도 안 닫히고, 천천히 끌면 닫힘
- 나머지 18개는 `duration: 0.2` 고정 트윈 — **중간에 잡아서 되돌릴 수 없음**
- 스크림은 트윈, 시트는 스프링 → **따로 움직임**

물리 계산이 컴포넌트 안에 흩어져 있으면 이 어긋남은 반드시 다시 생긴다.
**순수 함수로 뽑아 한 곳에 두고, 단위 테스트로 고정한다.**

## 디렉토리 구조

```
lib/motion/
├── gesture.ts        # 제스처 물리 — 투사·러버밴딩·닫기판정
├── spring.ts         # 스프링 파라미터 (Apple 스펙 → Framer Motion 변환)
├── types.ts          # 타입 (영어)
├── *.test.ts         # Vitest 단위 테스트 (1:1 필수, 커버리지 100%)
└── README.md         # 이 문서

hooks/
└── useDragSheet.ts   # 위 순수 함수를 React에 묶는 얇은 훅

components/ui/
└── DragSheet.tsx     # 공용 드래그 시트 프리미티브
```

### 계층 책임

| 계층 | 책임 | 금지 |
|---|---|---|
| `lib/motion/**` | 순수 계산만 | **React·Next·Supabase·UI import 금지** (ESLint 강제) |
| `hooks/useDragSheet.ts` | 포인터 이벤트 → 순수 함수 호출 → 상태 | 물리 계산을 인라인으로 쓰지 말 것 |
| `components/ui/DragSheet.tsx` | 렌더링·접근성·포털 | 판정 로직 금지 |

**왜 나누는가:** `lib/motion/`은 React를 import할 수 없다(ESLint 룰). 그래서 훅은 여기 못 산다.
대신 이 분리 덕분에 물리 계산이 **브라우저 없이** 테스트된다.

## 인터랙션 원칙 (Apple *Designing Fluid Interfaces* 기반)

새 제스처 UI를 만들 때 **반드시** 지킬 것. 각 항목은 위 순수 함수로 구현돼 있다.

### 1. 판정은 위치가 아니라 **속도**로 한다

```ts
// ❌ 손가락의 의도를 버린다
if (info.offset.y > 100) onClose();

// ✅ 던졌는지, 놓았는지를 본다
if (닫아야_하는가({ offset, velocity, height })) onClose();
```

빠르게 튕기면 조금만 움직여도 닫혀야 하고, 천천히 끌면 많이 움직여도 제자리로 돌아가야 한다.

### 2. 관성이 **데려갈 지점**으로 스냅한다

놓은 지점이 아니라, 감속 후 멈출 지점을 예측해서 그 근처 스냅 지점을 고른다.

```
투사거리 = (속도 / 1000) × 0.998 / (1 − 0.998)
```

교과서의 `v²/(2a)`가 아니라 **지수 감쇠 형태**다. iOS 스크롤이 쓰는 그 식이다.

### 3. 손가락 속도를 스프링에 **인계**한다

드래그가 끝나는 순간 애니메이션이 **속도 0에서** 시작하면, 시트가 한 번 멈췄다 다시 가속한다.
이 이음매가 보이는 순간 네이티브가 아니게 된다. 릴리즈 속도를 스프링 초기 속도로 넘긴다.

### 4. 경계에서 **점진적으로 저항**한다 (러버밴딩)

하드 스톱은 "얼었다"로 읽히고, 점진적 저항은 "반응하지만 더 없다"로 읽힌다.

### 5. 언제든 **잡아서 되돌릴 수 있어야** 한다

- 고정 시간 트윈(`duration`) 금지 — 중간에 못 잡는다. **스프링만 쓴다.**
- 인터럽트 시 **목표값이 아니라 화면에 보이는 현재값**에서 재시작한다.
- 애니메이션 중 입력을 막지 않는다.

### 6. 스크림과 시트는 **같은 스프링**에 물린다

따로 움직이면 즉시 어색하다. 배경 딤은 시트의 진행률(`progress`)에서 파생시킨다.

### 7. 피드백은 **누를 때** 즉시, 커밋 순간에 햅틱

- 하이라이트는 `pointerdown`에, 실행은 `pointerup`에.
- 시각·촉각은 **같은 프레임에** 떨어져야 한다.
- ⚠️ **`navigator.vibrate`는 iOS Safari에서 동작하지 않는다.** `lib/haptic.ts`를 쓸 것 —
  네이티브 셸에서는 `@capacitor/haptics`, 웹에서는 Vibration API로 자동 분기한다.

### 8. `prefers-reduced-motion`을 존중한다

끄는 게 아니라 **덜 어지러운 등가물**로 바꾼다. 슬라이드·스프링 → 짧은 크로스페이드, 오버슛 제거.

## 스프링 값 (Apple 스펙)

물리 3요소(mass/stiffness/damping) 대신 **감쇠비(damping ratio)** 와 **응답시간(response)** 으로 생각한다.

| 용도 | 감쇠비 | 응답 | 비고 |
|---|---|---|---|
| 기본 UI | `1.0` | `0.3~0.4` | 오버슛 없음. 대부분 여기 |
| 시트/드로어 | `0.8` | `0.3` | 약한 바운스 |
| 이동/재배치 | `1.0` | `0.4` | |

**오버슛은 제스처가 모멘텀을 실었을 때만 준다.** 그냥 페이드인한 메뉴가 튕기면 어색하고,
손으로 던진 카드가 튕기면 자연스럽다.

`spring.ts`가 이 값을 Framer Motion의 `stiffness`/`damping`으로 변환해준다. 직접 숫자를 쓰지 말 것.

> 참고: 기존 `MapBottomSheet`의 `damping: 28, stiffness: 300`은 감쇠비 ≈ 0.81, 응답 ≈ 0.36s로
> Apple 드로어 스펙과 거의 같았다. **값 자체는 옳았고, 빠진 건 속도 판정·인계·투사였다.**

## 새 시트를 만들 때

직접 `motion.div`에 `drag`를 붙이지 말고 **`<DragSheet>`를 쓴다.**

```tsx
import DragSheet from "@/components/ui/DragSheet";

<DragSheet open={open} onClose={close} label="장소 선택">
    {/* 내용 */}
</DragSheet>
```

`DragSheet`가 속도 판정·인계·투사·러버밴딩·스크림 동기화·햅틱·reduced-motion·포커스 트랩을
전부 처리한다. **새 시트에서 이 로직을 다시 구현하면 리뷰에서 되돌린다.**

### 이 앱 고유의 제약 (중요)

루트 레이아웃이 `html/body { overflow: hidden }` + `.main-content` **단일 스크롤 컨테이너** 구조다
(CLAUDE.md 레이아웃 규칙 참조). 따라서:

- `position: fixed` **사용 금지** — 스크롤 컨테이너 안에서 의도대로 동작하지 않는다.
  `DragSheet`는 `.mobile-viewport`로 **포털**해서 이 문제를 피한다.
- 배경 스크롤 잠금을 직접 구현하지 말 것. `.main-content`는 이미 `overscroll-behavior: contain`이다.
- 이 제약 때문에 **vaul 같은 외부 드로어 라이브러리를 쓰지 않는다.** 배경 스크롤 잠금 방식이
  이 구조와 충돌하고, 물리 계산이 라이브러리 안에 있어 단위 테스트가 불가능하다(커버리지 100% 불가).

## 테스트

```bash
npm run test:coverage    # lib/motion 커버리지 100% 검증
npx vitest run lib/motion
```

순수 함수라 브라우저·DOM 없이 돈다. 테스트는 **경계값**을 반드시 포함한다:

- 속도 0 (그냥 놓음)
- 임계 속도 정확히 (`= threshold`)
- 음수 속도 (위로 튕김)
- 경계 밖 오버슛 (러버밴딩)
- 감속률 극단값
